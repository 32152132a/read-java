# 后端实施计划

本文依据同级 `read-english/docs/backend-api-product-spec.md` 制定。Java 后端保持 `/api/v1`、字段语义、错误码和 MySQL 表语义与前端契约兼容。

## 模块顺序

1. 公共层：请求 ID、统一响应、异常处理、参数校验和 OpenAPI。
2. 认证：开发环境临时登录、JWT、微信登录 Gateway 外壳。
3. 学习流程：首页聚合、模板、用户流程、乐观锁和阶段推进幂等。
4. 内容与进度：课程单元、音标、答题、内容进度。
5. 词库：我的词库、可添加词库、批量添加和删除。
6. 异步能力：AI 词库、录音存储、口语评测和建议。

## 数据库迁移顺序

1. 用户、刷新令牌和登录身份。
2. 功能模板、用户流程、流程节点和当前流程位置。
3. 学习内容、音标、题目、选项和用户进度。
4. 系统词库、用户词库、单词和词库学习记录。
5. 幂等记录、异步任务、评测记录和纠音任务。

迁移使用 Flyway。数据库连接信息由环境变量提供，不向仓库提交密码。MySQL 安装完成后再加入数据源配置和首批迁移，避免当前应用因本地数据库未就绪而无法启动。
